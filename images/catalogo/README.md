# Pasta de imagens do catálogo

Salve aqui as fotografias reais, cada uma nomeada com o próprio código
cadastrado em `js/photos-data.js`, por exemplo:

```
VS-001.jpg
VS-002.jpg
VS-014.jpg
```

Isso evita erro de digitação: o nome do arquivo já corresponde ao código
usado no campo "image" de cada foto em `js/photos-data.js`.
